# 云川美术馆 · 团体参观预约 / 讲解设备借还 / 展厅分流调度台

面向美术馆工作人员的**团体参观全流程单页系统**：学校、企业、旅行社在线预约，馆方依据展厅容量、热门展品、讲解员排班、安检通道与临时闭展安排确认预约；到馆后完成人数核验、耳麦发放、讲解员派工与批次入场；讲解途中沿**同一条预约记录**处理拥堵、迟到、儿童走散、设备损坏、讲解员替换、游客改道、展厅维护等事件并联动参观顺序、设备押金、讲解时长与后续团队入场；离馆核销设备与押金、记录满意度；投诉时可回放完整证据链，支撑大团规则、排班与限流优化。

技术栈：**Vue 3 + TypeScript + Pinia + Vue Router + Vite**，纯前端工程（无后端依赖，数据由 Pinia + localStorage 持久化模拟）。

## 一、本地启动

### 方式 A：Docker 一键启动（推荐）

```bash
docker compose up -d --build
# 打开 http://localhost:8080
```

停止：`docker compose down`。容器内为 nginx 托管构建产物，已配置 SPA 路由回退与健康检查。

### 方式 B：Node 本地开发

要求 Node.js ≥ 18。

```bash
npm install
npm run dev          # http://localhost:5173，热更新开发
npm run build        # vue-tsc 类型检查 + 生产构建到 dist/
npm run preview      # 本地预览生产构建（默认 http://localhost:4173）
```

> 如遇 npm 全局缓存权限问题，可使用项目内缓存：
> `npm_config_cache=./.npm-cache npm install`

### 测试账号 / 视角

本系统为**无登录内网工作台**（演示），无需密码。在左侧边栏可切换：

| 视角 | 说明 |
| --- | --- |
| 馆方工作人员（默认） | 默认操作人「前台主管 沈姐」，可在侧边栏改名；所有操作留痕均记录操作人 |
| 团体联系人 | 可访问「团体预约」提交申请、在「全部预约」查看状态 |

数据每日重置演示：点击侧边栏 **↺ 恢复演示数据** 可清空 localStorage 回到初始状态。

## 二、页面与业务链路

| 页面 | 对应需求 |
| --- | --- |
| 🏛 运营看板 `/board` | 各展厅实时容量（含散客占用录入）、讲解员排班/带团热力图、设备库存（在库/借出/损坏/维修中/遗失暂扣）、**保洁查找任务与押金风险旅行社清单**、满意度与投诉、拥堵改道事件统计，自动给出**大团规则/排班/限流/押金加收优化建议** |
| 📝 团体预约 `/book` | 采集团体类型、人数、年龄层、语言、无障碍路线、讲解主题、到馆时间、联系人、车辆停靠、耳麦借用；提交即按主题生成建议动线并自动避让闭展/无障碍不可达展厅 |
| 📋 全部预约 `/reservations` | 按状态筛选、搜索，展开查看路线、押金与操作记录 |
| ✅ 预约确认台 `/confirm` | **15 分钟容量栅格**叠加本团预测满载率、临时闭展校验、大团拆批建议；按语言/主题/排班/带团冲突匹配讲解员；按到馆时段计算安检通道排队；可驳回 |
| 🏷 到馆前台 `/front` | 到馆登记（自动判定早到/迟到）→ 核验人数（差异提示）→ 从设备间发放耳麦并收押金 → 讲解员就位、批次安检入馆 |
| 🔀 途中分流调度 `/dispatch` | 七类现场事件：展厅拥堵、团体迟到/等待、儿童走散、耳麦损坏换机、讲解员替换、游客改道、展厅临时维护；**智能改道建议**（同主题/儿童友好/无障碍/相邻/满载率/热门与禁拍综合评分）+ **对后续团队入场的容量冲突预警**；改道自动顺延路线与讲解时长 |
| 🎧 离馆核销 `/checkout` | 逐台核对耳麦完好/损坏/缺失；缺失时登记**设备编号、借出人、团队负责人、最后使用展厅**，团队选择**现场寻找 / 押金暂扣 / 当场赔付**；保洁找回后按**设备完好（全额退押金）或损坏（扣维修费）**办结，确认无法找回则押金不退；损坏/遗失/维修中设备同步库存不再借出；满意度评分后结束预约 |
| 🔎 投诉与追溯 `/trace` | 一张档案展示：预约/实际到馆时间、人数差异、计划/实际讲解时长、分流决策与各厅说明、讲解员派工变更、展厅容量回放、设备借还与**遗失押金处置档案**（四要素、暂扣、找回结论、维修费）、完整操作时间线；可登记投诉并保存馆方答复 |

路线调整时，每个展厅卡片都明确标注：**🧒 儿童友好、♿ 无障碍可达、🤫 需保持安静、📷 禁止拍照、🔥 热门展品、🛠 临时维护、实时满载率**，兼顾馆内安静观展与团队体验。

### 关键业务规则

- 容量：展厅以 15 分钟为栅格汇总在馆团队人数 + 人工录入散客；≥85% 预警、≥100% 启动分流。
- 大团：≥35 人提示拆分，每批 ≤25 人、批间隔 ≥5 分钟。
- 无障碍：预约与路线生成自动剔除不可达展厅（四号厅），安检优先无障碍通道。
- 闭展：展厅静态维护时段与临时维护统一生效；确认时能在闭展后补看则顺延，否则标记跳过。
- 设备：耳麦标准押金 ¥200/台；**旅行社历史有确认遗失（当场赔付或暂扣后无法找回）的，后续团队按 ¥300/台 加收押金**；途中换机不重复收押金，旧机损坏挂账。
- 遗失处理：离馆清点缺失设备时登记设备编号、借出人、团队负责人、最后使用展厅；团队可现场寻找、押金暂扣或当场赔付。暂扣期间设备退出可借池；保洁找回完好则全额退押金并回库，找回损坏则扣维修费（默认 ¥80）并转「维修中」，确认无法找回则押金不退并计入该社遗失记录。损坏 / 遗失 / 维修中设备均不会再分配给下一场团队；未结案不能押金结算与离馆。
- 留痕：每一次确认、到馆、人数、设备、派工/换岗、分流、维护、押金、满意度、投诉都写入同一预约时间线，投诉追溯直接回放，不依赖人工回忆。
