# 云川美术馆 · 团体参观预约 / 讲解设备借还 / 展厅分流调度台

面向美术馆工作人员的**团体参观全流程单页系统**：学校、企业、旅行社在线预约，馆方依据展厅容量、热门展品、讲解员排班、安检通道与临时闭展安排确认预约；到馆后完成人数核验、耳麦发放、讲解员派工与批次入场；讲解途中沿**同一条预约记录**处理拥堵、迟到、儿童走散、设备损坏、讲解员替换、游客改道、展厅维护等事件并联动参观顺序、设备押金、讲解时长与后续团队入场；离馆核销设备与押金、记录满意度；投诉时可回放完整证据链，支撑大团规则、排班与限流优化。

技术栈：**Vue 3 + TypeScript + Pinia + Vue Router + Vite**，纯前端工程（无后端依赖，数据由 Pinia + localStorage 持久化模拟）。

## 一、本地启动

### 方式 A：Docker 一键启动（推荐）

```bash
docker compose up -d --build
# 打开 http://localhost:8080
```

停止：`docker compose down`。容器内为 nginx 托管构建产物，已配置 SPA 路由回退与健康检查。

### 方式 B：Node 本地开发

要求 Node.js ≥ 18。

```bash
npm install
npm run dev          # http://localhost:5173，热更新开发
npm run build        # vue-tsc 类型检查 + 生产构建到 dist/
npm run preview      # 本地预览生产构建（默认 http://localhost:4173）
```

> 如遇 npm 全局缓存权限问题，可使用项目内缓存：
> `npm_config_cache=./.npm-cache npm install`

### 测试账号 / 视角

本系统为**无登录内网工作台**（演示），无需密码。在左侧边栏可切换：

## 二、页面与业务链路

| 页面 | 对应需求 |
| --- | --- |
| 🏛 运营看板 `/board` | 各展厅实时容量（含散客占用录入）、讲解员排班/带团热力图、设备库存（含损坏/送修/遗失与**押金暂扣跟进清单**）、满意度与投诉、拥堵改道事件统计，自动给出**大团规则/排班/限流/保洁跟进/旅行社押金上浮建议** |
| 📝 团体预约 `/book` | 采集团体类型、人数、年龄层、语言、无障碍路线、讲解主题、到馆时间、联系人、车辆停靠、耳麦借用；提交即按主题生成建议动线并自动避让闭展/无障碍不可达展厅；**旅行社名称命中历史耳麦遗失档案时自动提示押金 1.5 倍** |
| 📋 全部预约 `/reservations` | 按状态筛选、搜索，展开查看路线、押金与操作记录；带「押金暂扣」「押金 1.5×」标记 |
| ✅ 预约确认台 `/confirm` | **15 分钟容量栅格**叠加本团预测满载率、临时闭展校验、大团拆批建议；按语言/主题/排班/带团冲突匹配讲解员；按到馆时段计算安检通道排队；对上浮押金的旅行社明示 ¥300/台；可驳回 |
| 🏷 到馆前台 `/front` | 到馆登记（自动判定早到/迟到）→ 核验人数（差异提示）→ 从设备间发放耳麦并收押金（**按 1 倍 / 1.5 倍费率**）→ 讲解员就位、批次安检入馆 |
| 🔀 途中分流调度 `/dispatch` | 七类现场事件：展厅拥堵、团体迟到/等待、儿童走散、耳麦损坏换机、讲解员替换、游客改道、展厅临时维护；**智能改道建议**（同主题/儿童友好/无障碍/相邻/满载率/热门与禁拍综合评分）+ **对后续团队入场的容量冲突预警**；改道自动顺延路线与讲解时长 |
| 🎧 离馆核销 `/checkout` | 逐台核对耳麦完好/损坏/遗失；标记遗失时登记**设备编号、借出人、团队负责人、最后使用展厅**，团队可选择**现场寻找 / 押金暂扣 / 当场赔付**；已离馆团的挂账设备可继续登记**保洁找回**——完好退押金、找回损坏扣维修费 ¥50、找不到转赔付 ¥200；满意度评分后结束预约 |
| 🔎 投诉与追溯 `/trace` | 一张档案展示：预约/实际到馆时间、人数差异、计划/实际讲解时长、分流决策与各厅说明、讲解员派工变更、展厅容量回放、设备借还/**遗失档案与暂扣-退还-维修费流水**、完整操作时间线；可登记投诉并保存馆方答复 |

路线调整时，每个展厅卡片都明确标注：**🧒 儿童友好、♿ 无障碍可达、🤫 需保持安静、📷 禁止拍照、🔥 热门展品、🛠 临时维护、实时满载率**，兼顾馆内安静观展与团队体验。

### 关键业务规则

- 容量：展厅以 15 分钟为栅格汇总在馆团队人数 + 人工录入散客；≥85% 预警、≥100% 启动分流。
- 大团：≥35 人提示拆分，每批 ≤25 人、批间隔 ≥5 分钟。
- 无障碍：预约与路线生成自动剔除不可达展厅（四号厅），安检优先无障碍通道。
- 闭展：展厅静态维护时段与临时维护统一生效；确认时能在闭展后补看则顺延，否则标记跳过。
- 设备：耳麦押金 ¥200/台；途中换机不重复收押金，旧机损坏挂账；离馆统一结算（损坏 ¥50、遗失 ¥200）。
- **耳麦遗失押金处理**：离馆清点少机时，前台在同一页面标记**设备编号、借出人、团队负责人、最后使用展厅**；团队三选一——🔍 现场寻找（押金暂缓）、⏸ 押金暂扣 ¥200（团队可先离馆）、💴 当场赔付 ¥200。保洁后续在「离馆核销」页按找回设备状态收尾：**完好→暂扣押金全额退还、设备回库**；**找回但损坏→扣维修费 ¥50、余额退还、设备转「送修」**；**仍未找到→转赔付 ¥200 结案**。
- **遗失影响旅行社信用**：存在未结案（寻找中/暂扣中）或已实际扣款（已赔付/找回损坏）遗失记录的**旅行社**，其后续预约耳麦押金上浮 **1.5 倍（¥300/台）**；全部完好找回后恢复 ¥200/台。学校/企业团体不适用该上浮。
- **库存同步**：押金处理后设备状态实时同步设备池——损坏、送修、遗失设备都不会再被分配给下一场团队；仅完好归还或完好找回的设备重新进入可借库存。
- 留痕：每一次确认、到馆、人数、设备、派工/换岗、分流、维护、押金、遗失登记/暂扣/找回/退还、满意度、投诉都写入同一预约时间线，投诉追溯直接回放，不依赖人工回忆。
